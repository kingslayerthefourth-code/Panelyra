# Panelyra Migration

## Canonical Installation

The current workspace is the canonical Panelyra development installation. The former product name is retained only in provider adapters, regression fixture names, the legacy export folder pending packaging, and legacy environment/profile fallbacks.

## Protected Data

Before migration, Panelyra captured:

- a source inventory in `backups/pre_panelyra_20260723/file-inventory.txt`;
- runtime checksums in `backups/pre_panelyra_20260723/runtime-checksums.sha256`;
- private configuration, history, markers, owner requests, uploads, and downloads in `backups/pre_panelyra_20260723/runtime-data.tar.gz`.

The virtual environment, OCR model cache, and generated bytecode were excluded because they can be recreated.

## Compatibility

- `PANELYRA_RUN_RECORD` is the preferred runtime variable.
- `ASURA_RUN_RECORD` remains accepted for older launchers and running processes.
- `PanelyraProfile` is preferred for Chrome.
- `AutomationProfile` remains the fallback when it already contains authenticated sessions.
- Root-level JSONL files and the `manhwa/`, `uploads/`, and `runs/` directories remain authoritative.
- `ocr_downloads/` remains visible as protected legacy output.

## Rollback

Do not remove the rollback snapshot until the renamed installation, browser profile reuse, dashboard pages, and all three automation workflows have been approved.
